Своё локальное «Избранное». Отправляйте текст и файлы между телефоном и компьютером по локальной сети — с устройства на устройство, без сервера посередине, который мог бы их хранить.

ЧТО УМЕЕТ

* Файлы и текст любого размера, напрямую между вашими устройствами по Wi-Fi
* Устройства находят друг друга по вашему же GitHub-аккаунту или по IP
* Лента всего, что вы отправили себе, с папками и архивом
* Встроенный плеер для присланного аудио и видео
* Голосовые сообщения, связывание по QR, перетаскивание на десктопе
* Замок с PIN и биометрией, локальное шифрование
* Android, Windows и Linux

ЧЕГО НЕ ДЕЛАЕТ

* Ни один файл не идёт через чужой сервер по дороге между вашими же устройствами.
* Ни аналитики, ни рекламных SDK.
* Ни подписки, ни лимита на размер, придуманного ради продажи лимита побольше.

Свободное ПО под GNU AGPL v3. Исходники открыты, сборки делает публичный CI из того же кода.
